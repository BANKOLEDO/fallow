Fallow

Sort a messy Downloads folder in minutes, with zero cloud upload.

Fallow reads filenames, size, age, extension and parent folder. You label a few dozen files by hand. It learns your preferences and predicts keep/archive/delete for the rest, using open-weight models (TabPFN + Gemma) on your machine. It only suggests; it never moves, renames or deletes files.

How it works

Fallow reads each file's size, age, type, folder and name. It never opens file contents. From the files you label, it learns what you tend to keep, archive or delete, and predicts the rest.

Classification runs entirely on your machine and costs nothing. Open-weight models (TabPFN, Gemma via Ollama) are the intended path, with a safe, loud fallback if unavailable.

Keep: things you reach for (docs, recent media)
Archive: old but worth keeping long-term
Delete: obvious clutter (temps, caches)
